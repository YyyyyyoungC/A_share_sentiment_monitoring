# A股情绪指数公式说明书

本体系用交易数据衡量市场风险偏好、损失扩散和下行压力。核心为六因子、0—100分的日度情绪指数，周报同时保留逐日变化和周内最严重预警。它不把情绪低位解释为买入信号，也不输出未经验证的“崩盘概率”。

版本：v1.0.0，固定先验研究版。行情观察截止2026年9月11日，最新完整交易周为9月7日至11日；资料与行情快照主要采集于9月14日，文档于9月15日整理。完整指数的历史逐股面板尚未齐备；本次完成的是公式、计算程序、价格分项实算、代表性压力案例核验与回顾性诊断，**没有把完整模型宣称为已通过实证验证**。

## 1. 结论与可用范围

建议优先使用“等权市场广度＋下跌尾部＋宽基趋势与下行波动”，融资行为给予较低权重。历史案例支持这个方向：2015年大量停牌会扭曲可交易样本；2024年2月5日创业板指上涨0.79%，财联社同时报道超过4800只股票下跌、个股中位数跌超9%。单一市值加权指数不能代表所有持仓者的感受。[^H1][^H7]

## 2. 市场范围与数据时点

### 2.1 中证全指与情绪统计池

中证全指代码为000985。官方基本信息及本次官网返回的2023年12月V1.2编制方案写明，样本来自沪、深、北三所符合条件的A股和红筹企业存托凭证；不是每日全部A股的简单平均。该方案排除ST、*ST，对科创板、北交所及其他证券有不同上市时间要求。历史复盘应保留各时期实际指数序列，不能将当前成分倒推至2015年。[^C1][^C2]

本模型的**个股广度主池**另作固定研究定义：沪深A股、当日非ST/*ST、非退市整理、上市至少60个交易日，并排除当日无涨跌幅限制等特殊交易状态。历史股票池必须包含后来退市的股票；60日是本模型的研究参数，不是中证全指编制规则。北交所、ST、新股分别作为扩展观察面板，首版不混入长期主池。

因此，价格因子使用全指、广度因子使用沪深成熟普通A股，两个统计范围不完全一致。这是明确保留的首版设计取舍。后续可另建统一沪深股票池的价格基准作为敏感性对照，但不能悄悄替换正式中证全指周表现。

### 2.2 时间与信息可得性

日度模型定义为北京时间18:00的收盘后监测。价格采用已经结束的交易日；个股状态、复权信息和行业标签使用当时可得版本。融资因子使用该时点**已发布的最近五日交易窗口**，通常滞后一个交易日，最多接受两个交易日的滞后。

保存四类时间：交易日期、首次可得时间、抓取时间、数据修订时间。历史后复权全序列、最终行业标签、今天仍上市的股票名单、后来补发的数据，都不能未经处理直接进入事前回测。报告中的未来20日收益只用于验证标签，不参与当日公式。

## 3. 指标筛选与优先级

下面覆盖主要公开可观测指标族，而非声称穷尽所有商业终端的私有指标。优先级依据可解释性、历史案例、可复算性、信息重复和制度稳定性；没有完整同口径面板时，不宣称某指标已被证明统计上“最有效”。

| 指标族 / 具体指标 | 主要反映什么 | 首版决定 | 主要限制 |
|---|---|---|---|
| 上涨/下跌/平盘数、涨跌家数比、AD线 | 当日参与度 | 净广度进入核心 | 必须控制股票池、停牌和漏抓；避免与多项同义广度重复计权 |
| 高于20/60日均线比例 | 持续性和损失扩散 | 20日比例进入核心，60日辅助 | 历史复权、短历史证券与停牌处理 |
| 个股收益中位数、等权指数 | 普通股票的实际表现 | 辅助校验 | 与涨跌广度部分重复 |
| 单日跌幅至少5%的比例 | 普遍抛售压力 | 进入核心 | 固定经济跌幅，不等于各板块法定跌停 |
| 新高/新低比例、创新低扩散 | 趋势恶化范围 | 辅助、待消融验证 | 新股、上市年限和回看期影响大 |
| 中证全指5/20/60日收益 | 宽基趋势 | 20日收益进入核心 | 市值加权，可能掩盖微盘或个股风险 |
| 20日下行半波动、实现波动、ATR | 下行风险与价格不稳定 | 下行半波动进入核心 | 滞后，不能解释为投资者情绪的直接观测 |
| 60/252日高点回撤、周内路径回撤 | 累积亏损 | 硬预警与复盘 | 与趋势、波动有相关性，不再加一组主权重 |
| 涨停率、跌停率、封板/炸板率 | 交易极端与短线接力 | 情绪线辅助面板 | 逐股法定价格、10%/20%/30%及ST、新股制度不同 |
| 连板高度、晋级率、昨日涨停次日收益 | 题材接力和赚钱效应 | 情绪线辅助面板 | 小样本、高度股幸存者偏差、一字板不可成交 |
| 成交额、换手率、量比、交易集中度 | 活跃度与拥挤 | 辅助，配合涨跌解释 | 放量上涨与放量下跌方向相反，不能机械加分 |
| 融资买入额减偿还额、融资余额 | 杠杆行为 | 净买入强度进入核心，余额辅助 | 发布滞后、融资标的含基金的可能性、余额不是流量 |
| ETF份额净变化、净申赎、折溢价 | 场内基金配置行为 | 资金线辅助 | 份额×净值的估算不等于精确现金流；不可用成交额代替 |
| 北向净买入、成交额、持股 | 跨境参与 | 分制度辅助，核心不纳入 | 披露口径变化；持仓变化、成交额和净买入不可互换 |
| 期权IV、偏斜、成交/持仓PCR | 尾部定价和保护需求 | 衍生品辅助 | 到期、标的覆盖、开平仓和套保方向混淆 |
| 股指期货基差、期限结构、持仓 | 套保与资金成本 | 辅助 | 换月、分红、资金利率以及交易制度变化 |
| 龙虎榜、大单/主力净流入、营业部集中度 | 特定交易行为 | 定性补充 | 软件大单分类不是全市场新增资金；披露选择性 |
| 开户、基金发行、募资、投资者调查 | 低频风险偏好 | 月度背景 | 不把旧月度值伪装成每日更新 |
| 搜索、新闻情感、论坛、社交热度 | 注意力与语言情绪 | 待独立研究 | 机器人、转载、删帖、平台模型变化和前视标签 |
| PE/PB、股息率、破净率 | 估值与中期背景 | 辅助 | 估值低不等于短期恐慌；行业和盈利结构改变 |
| 美股、美元、人民币、利率、港股 | 外部风险背景 | 外围面板 | 时区错位；相关走势不自动证明因果 |

核心因子限定六个，是为减少相似数据的重复计权。训练窗内若某两项Spearman相关性长期超过0.8，做删除一项的敏感性测试；这个数值是研究筛查规则，不是“无重复”的保证。

## 4. 六因子公式与权重

所有收益与比例先用小数计算，例如-3%记为-0.03。指数和个股日收益使用简单收益，不使用对数收益。个股除权除息必须校正，法定涨跌停判断则使用未复权价格与逐日限价。

| 因子 | 代码字段 | 原始公式 | 权重 | 原始值增大 |
|---|---|---|---:|---|
| 净涨跌广度 B | breadth | (U−D)/N | 20% | 偏暖 |
| 均线广度 M | ma20 | A20/N20 | 15% | 偏暖 |
| 全指20日动量 R | momentum | I(t)/I(t−20)−1 | 20% | 偏暖 |
| 个股急跌比例 T | tail5 | K5/N | 15% | 偏冷 |
| 下行半波动 DSV | downvol | sqrt(252/20 × Σmin(r(t−k),0)²)，k=0…19 | 20% | 偏冷 |
| 已披露融资强度 F | leverage | Σ五日(融资买入额−融资偿还额)/Σ同五日沪深A股成交额 | 10% | 偏暖 |

其中U、D、N分别为有效上涨、下跌、交易股票数量，平盘计入N；A20为价格高于自身20日均线的有效证券数，N20为具备有效20日均线的交易股票数；K5为当日除权校正收益≤-5%的证券数。均线历史可采用交易所连续交易日的除权一致价格序列，停牌日仅为均线连续性保留官方参考价；**停牌日不计入当日上涨、下跌、平盘或尾部样本**。对无法确定停牌参考价的股票，均线置缺失并计入覆盖检查。

融资分子必须明确是纯股票融资，或固定的交易所融资业务总口径；首版正式输入要求沪深A股股票范围，基金类融资需剔除。分母是沪深A股股票成交额，不含债券、基金、B股，也不使用中证全指行情接口的成分证券成交额替代。只有余额变动、只有汇总但不明标的范围时，该因子暂不合格。

下行半波动的20天分母包含所有20个交易日，非负收益贡献0；不是只在下跌日上计算标准差，252只是年化换算系数。

组别权重为：参与度35%、趋势20%、压力35%、杠杆10%。这些是**固定研究先验**：参与度与压力居主位，融资因滞后与口径问题较低；不是通过四次崩盘拟合得到的最优组合。

### 4.1 仅使用过去信息的分位数

对每个因子x，在t日前最多756个交易日位置内取历史值H。排除指标开始前的结构性预热区，但不跨过中途数据缺口去凑足756条。要求至少252个有效历史值，且有效率≥95%。当前值也必须有效。

```text
n = 有效历史值数量
rank(x_t) = 100 × [历史中小于x_t的数量 + 0.5×等于x_t的数量] / n

Q_B = rank(B)             Q_M = rank(M)
Q_R = rank(R)             Q_F = rank(F)
Q_T = 100 − rank(T)       Q_DSV = 100 − rank(DSV)

S = 0.20Q_B + 0.15Q_M + 0.20Q_R + 0.15Q_T + 0.20Q_DSV + 0.10Q_F
```

半秩处理并列值。例如历史[1,2,2,3]、当前2，分位数为50。低于全部历史可得到0，高于全部历史可得到100；全体相同为50。分位数不代表未来上涨概率。

取756日是平衡稳定性与制度适应性的先验；最低252日允许早期出分，252—755日属于扩展窗口阶段。本次价格分项首次可用日期为2012年9月12日。未来比较不同版本，应同时报告各因子的历史有效数量、窗口完整度和制度分段。

### 4.2 缺失、覆盖与降级展示

只有六项归一化分数全部有效才输出S；不填0、不填50、不重新分配剩余权重。抓取覆盖率为“收到且可计算的交易股票数/独立股票主表显示应交易股票数”，不足95%时广度、均线广度、尾部因子均无效。均线子样本还需N20/N≥95%。

停牌比例另算为`1−应交易股票数/合格股票总数`。这样不会把漏抓误认为停牌。存在未校验的ST历史、复权、退市证券或交易日历时，不应宣布完整模型数据合格。源数据审计标记是接入方的证据声明，不会由一个布尔值自动证明真实性。

在仅有全指价格的情况下，单独报告：

```text
P = 0.50Q_R + 0.50Q_DSV
正式模型有效权重 = 40%
完整S = NA
```

P的名称为“价格趋势/下行波动参考分”。它不能使用S的情绪分区，也不能因P≤10就确认全市场冰点。本周Q_R=22.4868、Q_DSV=19.8413，因此P=21.1640；完整S未知。仅从取值范围推导，S可能落在[8.47,68.47]，这只是缺失输入的数学可行范围，不是统计置信区间。

## 5. 状态分区与预警

### 5.1 完整S的初始状态分区

| S区间 | 描述 |
|---|---|
| 0—10 | 极端低迷 / 相对冰点 |
| >10—25 | 恐慌或低迷 |
| >25—45 | 偏弱 |
| >45—55 | 中性 |
| >55—75 | 偏强 |
| >75—90 | 亢奋 |
| >90—100 | 极端亢奋 |

这些是初始运维阈值，尚未证明最优。低分可由长期低迷形成；“崩盘”还须原始价格、尾部和交易可用性证据。高分不表示未来必跌。

### 5.2 独立于均值的硬预警

每个交易日检查全部条件，取最高级别；同时保留所有原因。阈值包含等号。

| 级别 | 任一条件触发 |
|---|---|
| 红色，3 | 全指日收益≤-5%；5日收益≤-10%；个股急跌比例≥20%；下行半波动历史分位≥99且日收益≤-3%；完整S连续2日≤10；周内收盘路径最大回撤≤-8% |
| 橙色，2 | 日收益≤-3%；5日收益≤-6%；急跌比例≥10%；完整S≤20；周内收盘路径回撤≤-5%；周内高低价比幅度≥10%；日上涨≥5%（标为正向剧烈波动） |
| 黄色，1 | 日收益≤-2%；下行半波动分位≥95且当日下跌；完整S≤30；完整S≥90（过热观察）；日上涨≥3%且<5% |
| 数据提示 | 任一核心因子缺失、应有交易日未更新、报价覆盖不足；合格股票停牌/无成交比例≥10%另提示交易可用性风险 |

`r5=I(t)/I(t−5)−1`是滚动五日收益，不一定等于自然周收益；周收益必须用本周末/上周末−1。周内收盘路径包含上周末收盘作为起点，按先后顺序计算峰值到后续收盘的回撤。高低价比幅度定义为`max(本周high)/min(本周low)−1`，不是常见的“高低差/上周收盘”，也不假定高点发生在低点之前。

周报保留本周最严重级别、各触发日期与原因，即使周五反弹也不能删除周一的风险事件。当前脚本实现逐日与周内汇总；跨周事件编号、连续两日解除、通知去重可在生产监控层增加。本次没有创建定时任务，也没有发送外部提醒。

### 6.2 为什么低分不等于见底

## 9. 如何判断指标是否真的有效

完整面板补齐后，以以下标准决定是否保留指标和权重，不用案例“看起来对”代替验证。

1. **固定版本与目标。** 区分当日压力描述、未来压力预警、未来收益预测。冻结股票池、六项公式、权重、窗口、阈值和缺失机制。
2. **走向前检验。** 每年只用此前数据做训练/筛选，验证下一年；当前已研究的危机年份只能称回顾性或伪样本外检验。真正未见样本从本版冻结后的持续运行开始。
3. **独立标签。** 可定义未来5/20日内最低收盘相对当前下跌≥5%/10%的事件，标签不进入当日因子。重叠标签按最长20日窗口purge/embargo，禁止普通随机K折。
4. **基线和消融。** 与仅日跌幅、仅20日趋势、等权分位组合比较；分别去掉融资、广度、尾部，并调整756/504/252日窗口做稳健性分析。所有选择只在训练段进行。
5. **事件而非交易日重复计数。** 报告危机事件召回、每年误报次数、首次提醒提前天数、提醒后继续下跌幅度、警报持续时间、缺失覆盖和制度分段结果。
6. **收益另行检验。** 若未来用于交易，还要纳入成本、停牌、跌停无法卖出、一字板无法买入、退市和指数不可直接交易等约束。不用某个分组平均收益代替可执行策略。

本次12项主测试与8项独立审查测试均通过。主测试已覆盖半秩、历史覆盖、截断无前视、缺项不重配、融资延迟可得性、非法计数、覆盖不足、重复日期与异常OHLC、周收益基点、周中预警保留、正向剧烈波动和过期/缺日数据。测试验证的是程序计算与控制，不是预测有效性。历史全模型相关性、权重优劣、误报率、真实前向表现仍待合格面板与持续监测。

## 10. 日常报告与生产运行

每日收盘后更新基础数据、验证时间与覆盖、计算六因子、保存原值/分位/来源，再生成逐日事件。每周完整周报告采用最后实际交易日，并列上周末、周均、周内最低及对应日期，汇总本周所有警报。

周报固定保留：情绪与数据质量、中证全指周表现、预警原因、行业表现、短线情绪资产、融资/ETF等资金证据、外围市场及其发布时间。只有实际数据改变才改变结论；数据缺失时给出缺项和已覆盖范围。

当前脚本默认取已经结束的上一个周五，避免误用盘中数据。逢节假日，应提供独立交易日历，或显式指定已核验的最后交易日；周中指定日期属于“截至该日”的观察，不得称完整周。公网接口并无稳定服务保证，正式运行应保留原始快照、文件校验和、行情日历检查以及失效告警。
